# 🥋 رزمیار (Razmyar Web Frontend)

> **رابط کاربری و پنل ابری هوشمند مدیریت باشگاه‌ها و ورزش‌های رزمی**  
> توسعه‌یافته با **Next.js 16 (App Router) + React 19 + Tailwind CSS v4 + TypeScript**

---

## 🎨 ویژگی‌های ظاهری و فنی فرانت‌اند

- **کاملاً فارسی و راست‌چین (RTL):** تایپوگرافی چشم‌نواز با فونت استاندارد **وزیرمتن (Vazirmatn)**.
- **تم تیره ورزشی (Modern Dark Theme):** سازگار با متغیرهای رنگی مدرن OKLCH و کنتراست ارگونومیک برای مربیان در محیط سالن.
- **نمودارهای تحلیلی مهارتی:** نمایش نمودار رادار ۵ محوره مهارت‌ها (تکنیک، فرم، مبارزه، بدنسازی، انضباط) و خطوط رشد با **Recharts**.
- **سامانه براکت‌های حذفی مسابقات:** رندر دینامیک درخت مسابقات حذفی تک‌حذفی با قابلیت ثبت نتایج بازی‌ها.
- **انتخاب چندباشگاهی هوشمند (Multi-Club Selector):** امکان جابه‌جایی سریع بین شعب باشگاه برای مربیان و مدیران.
- **احراز هویت و محافظت از صفحات (Route Guards):** میان‌افزار Next.js برای بررسی انقضای نشست کاربری و کنترل دسترسی نقش‌ها.

## 🗺️ نقشه صفحات و مسیرهای سامانه

| مسیر | عنوان | توضیحات |
| :--- | :--- | :--- |
| `/login` | ورود مربی | فرم لاگین امن مربی با ایمیل و رمز |
| `/dashboard` | داشبورد مدیریت | ویجت‌های تحلیلی، خلاصه آزمون‌ها و شاگردان نیازمند توجه |
| `/students` | بانک شاگردان | فهرست شاگردان، فیلتر کمربند، وضعیت و افزودن پرونده |

| `/students/[id]/analysis` | هوش مربیگری | تحلیل نقاط قوت، نقاط نیازمند تقویت و برنامه تمرینی اختصاصی |

| `/competitions` | مسابقات و براکت‌ها | جدول مسابقات حذفی، راندها و رده‌بندی مدال‌آوران |
| `/settings` | تنظیمات باشگاه | تغییر نام باشگاه، حدنصاب قبولی و مشخصات استاد |

## ⚙️ متغیرهای محیطی (Environment Variables)

یک فایل `.env.local` در این پوشه بسازید (می‌توانید از روی `.env.example` کپی کنید):

```env
# آدرس API سرور بک‌اند (روی Vercel آدرس سرور Render را قرار دهید):
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

## 🚀 راهنمای اجرا در محیط توسعه (Local Development)

```bash
# ۱. نصب پکیج‌ها
npm install

# ۲. اجرای سرور توسعه فرانت‌اند
npm run dev
```

سامانه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

### ساخت بیلد پروداکشن (Production Build):
```bash
npm run build
npm run start
```

## 🌐 استقرار رایگان روی Vercel (Deployment)

1. وارد [Vercel.com](https://vercel.com) شوید و دکمه **Add New Project** را بزنید.
2. ریپازیتوری `razmyar-ap` را انتخاب کنید.
3. در بخش **Environment Variables** متغیر زیر را اضافه کنید:
   - **Key:** `NEXT_PUBLIC_API_URL`
   - **Value:** آدرس بک‌اند دیپلوی‌شده در Render (مثلاً: `https://razmyar-api.onrender.com/api`)
4. دکمه **Deploy** را بزنید. فرانت‌اند در کمتر از ۱ دقیقه آنلاین می‌شود.
